# BitDinghy typography

**Primary font:** Inter, with platform system sans-serif fallbacks. No bundled font binaries.

- Headings: Inter 700-800; desktop 28-40px, mobile 24-32px.
- Body: Inter 400-500; 16px base with 1.5 line height.
- Buttons & labels: Inter 600-700; 14-16px.
- Numeric counters / logs: system monospace when alignment is important.

These sizes are sensible web defaults, not exact typography measurements from the concept board. Install Inter yourself if desired, or rely on the fallback stack in `brand/colors.css`.
